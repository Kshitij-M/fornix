# Fornix reference repository

This small fixture is the first executable showcase of Fornix's product
direction: verifiable AI work for repository operations.

The deterministic reference workflow indexes this repository, retrieves bounded
context, asks the fake provider to inspect it through a registered read-only
structured-argv tool, and stores a hash-addressed report with evidence. It is
deliberately safe and read-only today. Future repository-maintenance workflows
will extend the same path into a Verified Change Packet with validation and
reviewable changes.
